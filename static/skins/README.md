# Skin images

## `zune/` and `royale-noir/`

Window chrome, taskbar, Start menu and button images from the **Windows XP Zune** and **Windows XP Royale Dark**
themes by the B00merang Project: https://github.com/B00merang-Project/windows-xp

Licensed under the **GNU General Public License v3.0** (full text in `LICENSE`). `frame.png` is assembled from
that project's window border images; everything else is copied as-is and renamed. Used by
`assets/css/skins/zune.css`, `royale-noir.css` and `xp-shared.css`.

## `xp-icons/`

Icons from the **Windows XP** icon theme by B00merang Artwork: https://github.com/B00merang-Artwork/Windows-XP

Licensed under the **GNU General Public License v2.0** (full text in `xp-icons/LICENSE`). Scaled to 16×16 and
32×32 and renamed to the theme's icon names. The XP looks use them in place of `static/icons/` (see
`data/themes.yaml`, `icons: xp`).
